# E-Commerce Product Scraper

A Python web scraper that extracts publicly available product information from e-commerce websites.

## Data Extracted

- Product Name
- Price
- Rating
- Review Count
- Product URL

## Technologies

- Python
- Playwright
- Pandas

## Output

- CSV
- Excel
- JSON

## Features

- Automated browser navigation
- Product data extraction
- Pagination handling
- Data cleaning
- Duplicate removal
